### Hi, I'm Ninon.

I like making apps and small tools, mostly things I want to use myself. Some are already being used, and some are still experiments.

I also like testing what I make. When I have results, I share them, even if they're not as good as I hoped.

- [Dayside](https://github.com/ninondev/Dayside) is a world clock for the Mac menu bar. Every city has its own row with the color of its sky right now. The release build has no network permission.

- [stove](https://github.com/ninondev/stove) is for kitchen ticket printing and a take-a-number queue. I took these parts from a restaurant ordering system that's been in regular use since August 2026.

- [dryport](https://github.com/ninondev/dryport) is an experiment to run some Windows-only games on Apple silicon Macs. For Unity games, it can turn D3D11 shaders into Metal instead of using Wine. *A Space for the Unbound* passed all five checks on an M5 Mac.

- [verbatim-quote](https://github.com/ninondev/verbatim-quote) checks if a quote really appears in the original text, character by character. In one test, changing a number still gave a similarity score of 0.96, but this tool rejected it.

- [SpeakFB](https://github.com/ninondev/speakfb) is a little tool for my English speaking practice. It takes a recording and shows my speaking speed, long pauses and filler words. Transcription runs on the Mac.

I also trained a small model with 149 million parameters to score English exam essays. I finished it in August 2026, about three weeks before TypeSafe released Jev. Like Jev, it gave scores on an ordered scale instead of generating text, but mine only worked with one type of essay.

I tested it on 84 essays that had been marked by people. Its scores were within one band of theirs 88% of the time. My goal was 94%, so I didn't quite get there. I've since deleted it.

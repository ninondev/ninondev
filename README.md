### Hi, I'm Ninon.

I make tools I use every day, measure them, and publish the numbers, including the ones that did not go my way.

| Project | What it does | One fact |
|---|---|---|
| [Dayside](https://github.com/ninondev/Dayside) | Mac menu-bar world clock. Each city's row is painted in the real color of its sky right now. | The release build has no network permission. |
| [Claude-sama](https://github.com/ninondev/claude-sama) | Unofficial fan mod that makes Claude Code cute: a small kami lives above your prompt. | No extra model calls to be on screen. |
| [verbatim-quote](https://github.com/ninondev/verbatim-quote) | Checks that a quote really appears in its source, character for character. | Rejects a changed number that a 0.96 similarity score accepts. |
| [SpeakFB](https://github.com/ninondev/speakfb) | A speaking report for English recordings: pace, long pauses, fillers. | Transcription runs on your Mac. |

More are on the way this month. Each repository has a short CLA, so I can keep offering the code under other terms later.

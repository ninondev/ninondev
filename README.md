### Hi, I'm Ninon.

I make tools I use every day, measure them, and publish the numbers, including the ones that did not go my way.

| Project | What it does | One fact |
|---|---|---|
| [Dayside](https://github.com/ninondev/Dayside) | Mac menu-bar world clock. Each city's row is painted in the real color of its sky right now. | The release build has no network permission. |
| [stove](https://github.com/ninondev/stove) | Prints kitchen tickets and runs a take-a-number queue for a restaurant. | It comes from an ordering system in regular use since August 2026. |
| [dryport](https://github.com/ninondev/dryport) | Runs some Windows-only games on Apple silicon Macs. For Unity games it rewrites their D3D11 shaders as Metal instead of using Wine. | A Space for the Unbound passed all 5 of its checks on an M5 Mac. |
| [verbatim-quote](https://github.com/ninondev/verbatim-quote) | Checks that a quote really appears in its source, character for character. | Rejects a changed number that a 0.96 similarity score accepts. |
| [SpeakFB](https://github.com/ninondev/speakfb) | A speaking report for English recordings: pace, long pauses, fillers. | Transcription runs on your Mac. |

I also trained a small model (149M parameters) to mark essays for an English exam, and finished it in August 2026, 3 weeks before TypeSafe released Jev. Like Jev, it returned scores on an ordered scale instead of writing text, but it only marked 1 kind of essay. On 84 test essays marked by people, its marks were within 1 band of theirs 88% of the time, close to my 94% target but under it. I've since deleted it.
